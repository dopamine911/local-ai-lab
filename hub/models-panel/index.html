How this page works

Each box is one card. It shows how much memory is free (one block is 1 GB), the models loaded on that card, and the models that can load there. On marvin the GPU shares the system's memory.

Click a model's name to see what it is, its last speed and its full config. Load and Unload ask first.

A model runs on one card, fixed in its config. To use the other card, load that card's entry: coder is card 1, coder-2 is card 2. Loading a model can unload others that cannot run next to it; the details say when.

Training and image mode are switched with lab training-mode and lab image-mode. The page refreshes every 5 seconds and waits while a model's details are open.
