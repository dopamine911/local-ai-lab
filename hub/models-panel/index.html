Each block in a meter is 1 GB. On marvin the GPU shares the system's memory, so its meter shows both.

Load starts a model. llama-swap first unloads any model that cannot run next to it; a model that runs alone (gpt-oss, coder-long, coder-radiance) unloads everything else on zaphod. Unload stops a model and cuts any answer it is writing.

Each entry runs on one card, fixed in its config. To use the other card, load that card's entry: details lists them under "same file". Training and image mode are switched with lab training-mode and lab image-mode.

Speed is the latest lab speed run in MLflow. The page refreshes every 5 seconds, and waits while a model's details are open.
