Load sends one request to the model; llama-swap starts it and unloads whatever its routing sets say cannot run next to it (for example, gpt-oss and coder-radiance run alone: everything else on zaphod unloads).

Unload stops the model; a request it is answering is cut. Profiles (training, image mode) are switched with lab training-mode and lab image-mode, not here.

Speed: the latest lab speed run in MLflow (writing / 32K reading, tok/s). Refreshes every 5 s, paused while a model's details are open.

Card: each entry runs on a fixed card, set in its command (--device: llama.cpp calls card 1 Vulkan1, card 2 Vulkan0). To use another card, load the entry for that card; "same file" in the details lists them.
